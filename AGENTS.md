# AGENTS.md

Before any task:

1. Read RULES.md and follow it.
2. Open TASKS.md, find the task, confirm its dependencies are done, and mark it `[~]`.
3. Read DECISIONS.md before changing an existing approach.

Refer to PRD.md, ARCHITECTURE.md and DESIGN.md as needed. DESIGN.md wins on implementation detail; if documents conflict, stop and ask.

After each task, update TASKS.md and record any new decision in DECISIONS.md.
